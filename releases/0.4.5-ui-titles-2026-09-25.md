# Orion 0.4.5 — UI and article titles, 25 September 2026

- Short selections offer **Generate title with AI** in the link composer. Naming
  uses the existing bounded, cancellable, Space-local title-resolution flow.
  The default still uses the selected words; the original prose remains intact.
- New note → Generate writes a concise article title in the same response as its
  body. Orion saves the title and slug, removes the duplicate heading from the
  body, and preserves any title edited while generation was running.
- Includes the continuous curved content border in solid mode, selected-note
  outline removal, Hanken Grotesk/Lora typography, editor font choice, and sidebar
  footer changes from the earlier UI refresh.

The standard Apple Silicon installer bundles Whisper Small and preserves the
existing `app.orion.knowledge` vault. No logo change is included in this build;
the refined teal/cobalt Imprint O is the proposed icon.
