# Orion 0.4.5 — theme icons and daylight atmospheres

Theme colours now carry through to the freestanding O, running Dock icon, and
Finder icon. The approved shape and transparent centre stay intact; only its
lighting colours change. The finish deepens in dark mode and lightens in light
mode. Settings → Appearance → Icon colours offers Theme and Original. Original
restores the packaged icon and clears the Finder custom icon.

Finder updates use Apple's public NSWorkspace custom-icon API on the running
app's own bundle. Signed resources remain untouched. Finder keeps the last
colour after quitting; updates resume at launch. Read-only installations report
the limitation while the in-app and Dock icons continue working. System mode
follows live macOS appearance changes. Rapid colour edits are debounced and
native updates are serialized; background windows cannot replace the active
window's icon.

Light-mode atmospheres now use a gently shaded paper room and richer coloured
midtones. Mirage, Prism Drift, Tidal Glass, Gravity Silk, and Quiet Loom have
separate daylight surface lighting with controlled highlights. Home atmosphere
→ Appearance offers Match theme and Always dark. The latter keeps only the hero
dark, with matching readable text and controls. Existing two-colour, motion,
glass, and typography choices remain available.

Existing vaults accept both optional preferences. The app identity and vault
location remain app.orion.knowledge; no library migration or reset is needed.
