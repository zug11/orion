# Orion 0.4.5 — Space overview recovery

Across this Space could repeatedly summarize an old starter description even
when its note contained a substantive transcript. The single-cluster shortcut
skipped cluster synthesis but then sent the cached cluster prose to the root
request, omitting current note digests. The old fingerprint also omitted the
derived summary, so removing starter copy did not invalidate that cached prose.

Small Spaces now send every current typed note digest, including its whole-body
sketch, directly to the root overview request. The result replaces both the root
and its single leaf. A versioned digest fingerprint invalidates obsolete caches
without changing notes or timestamps; rebuilt roots exclude obsolete overview
text. Larger Spaces retain the sequential hierarchy and require completed child
synthesis. Oversized root requests fail explicitly instead of clipping JSON or
dropping later notes.

After installing, opening an affected Space schedules its normal overview
refresh when AI is configured and existing-note context is enabled. The existing
Refresh Space overview button uses the same corrected path. App identity, vault
location, notes, sources, and settings remain compatible.
