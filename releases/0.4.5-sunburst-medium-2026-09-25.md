# Orion 0.4.5 — Whisper Medium and Sunburst

This Apple Silicon installer includes the current desktop improvements and
Space-overview recovery fix, with Whisper Medium selected for both the bundled
model and the renderer's dictation behavior.

- Dictation uses one persistent Whisper Medium worker and 30-second windows
  with two seconds of acoustic overlap. Completed segments are buffered until
  Stop, when Orion inserts the combined transcript into the note.
- Selected-passage illustrations and slide images use the OpenAI model
  `gpt-image-2.5-sunburst`, retaining medium-quality JPEG output. This is an API
  integration, not a bundled offline image model; it requires an OpenAI key.
  The Image API has no documented Fast mode parameter.
- Across this Space reads current note-body digests in small Spaces and
  invalidates obsolete cached starter summaries without changing the notes.
- The production app identity and vault location remain `app.orion.knowledge`.
  Replacing the app keeps the existing library and settings.

## Installer

`outputs/Orion-0.4.5-sunburst-medium-2026-09-25.m-Apple-Silicon.dmg`

Build with:

```sh
ORION_WHISPER_MODEL=medium ORION_NOTARY_PROFILE=orion-notary \
  ./script/package_release.sh 0.4.5-sunburst-medium-2026-09-25.m
```
