# Orion 0.4.5 — UI refresh, 25 September 2026

- Solid window mode now separates the reading canvas with a continuous top and
  left border joined by a rounded inner corner. The top bar and sidebar remain
  one frame; Liquid Glass retains its current appearance.
- Selected sidebar notes retain their full-row highlight without the partial
  outline that stopped before the delete control. Keyboard focus stays visible.
- Includes the Hanken Grotesk and Lora typography refresh, the editor's shared
  Sans serif / Serif choice, and the revised sidebar footer layout.

This standard Apple Silicon installer bundles Whisper Small and uses the existing
`app.orion.knowledge` library. Updating the application does not replace the vault.
Orion Preview keeps a separate library.
