The **Orion preview for Windows 11 x64** now includes the Claude Desktop
extension and the Codex plugin.

Download the Windows setup EXE under **Assets** and run it. Setup installs for
the current user and can fetch Microsoft Edge WebView2 if it is missing. This
preview is unsigned, so Windows may show a SmartScreen prompt. The installer
SHA-256 is included alongside the EXE.

Open Orion once and go to **Settings → Connections**.

- **Install in Claude** opens the bundled extension. If Orion shows a file
  path, open **Claude Desktop → Settings → Extensions → Advanced settings →
  Install Extension** and select that file.
- **Install in Codex** opens Orion's plugin page. Choose **Install** there.

Both integrations discover your local Orion library automatically. They can
search Spaces, read sources and notes, return Orion citations, and create,
edit, or delete notes in an explicitly selected Space. Direct vault tools work
while Orion is closed.

To use workflows with Orion open, enable **Orion workflows** in Connections
and select the Spaces to share. You can grant AI use and workflow writes
separately.
