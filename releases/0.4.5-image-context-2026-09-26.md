# Orion 0.4.5 — Context-aware illustrations, Whisper Medium

Selected-passage image generation now uses the Space's selected Intelligence
model to find relevant notes and preserved source passages, then compose a
visual brief for `gpt-image-2.5-sunburst`. It uses captured live editor context
and respects the existing Space-context preference. Planning is read-only;
cancelled or stale requests cannot proceed to the image-generation stage.

The Apple Silicon installer retains Whisper Medium, its persistent worker and
30-second dictation windows, along with the current UI and Space-overview fixes.
The production identity and vault location remain `app.orion.knowledge`.

## Reproduction

Run the canonical release script from a clean copy of the current source,
including the new image-planning files, with the real `src-tauri` directory
inside that release root:

```sh
ORION_WHISPER_MODEL=medium ORION_NOTARY_PROFILE='' \
  ./script/package_release.sh 0.4.5-image-context-2026-09-26.m
```

Submit the signed installer through the existing `orion-notary` Keychain
profile with `xcrun notarytool submit --no-s3-acceleration --wait`, then staple
and validate the ticket and assess the DMG with Gatekeeper. Direct S3 upload
avoids the interrupted accelerated upload encountered on the previous release.
