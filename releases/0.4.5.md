# Orion 0.4.5

Orion 0.4.5 brings the app's AI and knowledge workflows to Codex and Claude
Desktop, expands the shared connector to 41 tools, and includes the two-tone
shader picker.

## What's new

- **Orion AI through MCP.** Connected assistants can request scoped context,
  research, imports, source reprocessing, generation, canonical articles,
  enrichment, and Space overview refreshes through the running Orion app.
  Orion uses its configured provider and model; provider keys stay in Keychain.
- **41 tools for Codex and Claude Desktop.** Twenty-nine local library tools
  cover notes, preserved sources, exact passages, concepts, aliases, provenance,
  related notes, tasks, tags, recent changes, duplicates, and integrity checks.
  Twelve workflow and job tools connect to the app's existing intelligence.
- **Precise edits.** Version-guarded replacements, appends, task completion,
  and atomic metadata batches reject stale targets before anything is saved.
  Results retain exact Space IDs and Orion citations.
- **Workflow controls.** Settings lets you choose allowed Spaces and enable
  Orion AI and workflow writes separately. Jobs support bounded results,
  progress, cancellation, and retry protection. Local library tools remain
  available with Orion closed and without a provider key.
- **Two-tone shaders.** Choose Colour 1 and Colour 2 with native colour pickers
  or hex values, see the pair in the atmosphere previews, and reset both
  together. The colours persist across restarts and work with the expanded
  Home atmosphere gallery.
- **Local dictation.** Record from the sticky note toolbar while retaining the
  insertion point. The standard installer bundles Whisper Small and processes
  bounded two-minute segments on-device. The Medium installer loads Whisper
  Medium once per dictation and processes overlapping 30-second windows. Both
  keep transcription on-device and insert the combined transcript when
  recording stops.

## Downloads

- **Orion-0.4.5-Apple-Silicon.dmg** — standard Whisper Small installer; drag
  Orion into Applications. Requires Apple Silicon and macOS 13.3 or later.
- **Orion-0.4.5.m-Apple-Silicon.dmg** — Whisper Medium installer with the same
  Orion 0.4.5 features, two-tone shader picker, and connectors. Installing one
  edition replaces the other; they use the same local library.
- **Orion-Claude-Connector-0.4.5-Apple-Silicon.mcpb** — standalone Claude
  Desktop connector.
- **Orion-Codex-Plugin-0.4.5-Apple-Silicon.zip** — standalone Codex plugin.
- **SHA256SUMS.txt** — checksums for the four downloads.

The installers and nested executables are Developer-ID-signed. Apple
notarization is pending authorization; no notarization ticket is claimed.

## Verification

- 879 renderer tests passed, with one existing test skipped; TypeScript and the
  production renderer build passed.
- All seven focused dictation and transcript tests also passed with the Medium
  edition selected.
- All 65 native tests and 45 MCP tests passed, along with Rust formatting and
  release-script syntax checks.
- Both final APFS disk images passed checksum verification. Orion.app was copied
  out of each exact image and passed strict verification of nested signatures,
  source and renderer fingerprints, the selected model's exact size and
  checksum, and all four native helper version checks. The Medium installer is
  1,501,342,986 bytes and bundles the 1,533,763,059-byte Whisper Medium model.
- Claude and Codex connector checks, including all 20 new library tools, passed
  against the actual packaged executables and the copies extracted from both
  DMGs.
- The built two-tone picker was checked at 1280 × 900 and 1024 × 680, including
  separate colour changes, persistence after reload, keyboard focus, and reset.
  There was no horizontal overflow or browser console error.

## Known limitations

Verification used isolated fixtures and an empty browser-preview library. It
did not use a personal Orion library or make paid provider calls. Live provider
quality and an end-to-end workflow in an installed Codex or Claude Desktop
client were not re-tested for this release. Helper version checks do not claim
a complete YouTube download and transcription test.

Dependency versions are unchanged. The packaging audit reported 35 dependency
vulnerabilities: 33 moderate and two high. This release does not claim fixes for
those existing dependencies.
