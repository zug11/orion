# Orion 0.6.3

Make boards fit your work, and return to a Space where you left it.

- Keep To do, In progress and Done, and add extra kanban columns for stages such as Review or Blocked.
- Rename boards and any column without changing ticket identities or completion behaviour.
- Move tickets into custom columns by drag or keyboard. Columns and their names survive Markdown, exports, copy/paste and MCP operations.
- Search Space names directly in the Space switcher. ArrowDown focuses results; Enter opens a single match.
- Return to each Space's previous view and scroll position in the current window session.
- Fix ticket Details rejecting description and checklist edits while editing a note when title whitespace differs from its saved form. Genuine conflicts remain protected, and Undo still works.

For Apple Silicon Macs running macOS 13.3 or later. Includes on-device Whisper Medium and signed in-app updates.
