# Orion 0.5.3 — multiwindow refresh fix

10 November 2026. Apple Silicon, Medium transcription edition.

An asynchronous library refresh could arrive after the same window's autosave
had advanced its saved version. Orion could then mistake its own earlier text
for an edit made in another window, or briefly restore that older text.

Refreshes now recheck the save queue and the persisted merge base after loading.
A read overtaken by saving is discarded and retried against current disk data.
Ordinary autosave, real competing-edit choices, independent window navigation,
and the native lock/revision protocol retain their existing behavior. The prior
typing-latency and optional-heading improvements remain included.

passed with one existing ignore, and 114 connector tests passed. Production
build and formatting checks passed. Two live browser views verified synchronized
typing, disjoint field edits, genuine conflict resolution, Undo/Redo and reload.
Desktop and narrow layouts were checked without browser console errors.
