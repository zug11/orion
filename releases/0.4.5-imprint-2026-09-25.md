# Orion 0.4.5 — Imprint icon, titles and frame polish

## Changes

- Use the selected teal/cobalt Imprint O without the wordmark for the macOS app,
  sidebar, browser favicon, and bundled Claude/Codex connectors.
- When Liquid Glass is off, join the content canvas's top and left borders with
  one rounded corner. Remove the partial outline inside a selected sidebar note.
- Add an optional **Generate title with AI** checkbox when creating an article
  from a short selected phrase. The original selected text remains unchanged.
- Generated notes receive an AI-written article title instead of retaining the
  writing instruction. Keep any title the user edits while generation runs and
  preserve explicit titles supplied through the connector.

## Data compatibility

The app identity remains `app.orion.knowledge`. Installing this build retains
the existing vault and preferences. No vault migration or data reset is added.
