# Orion 0.4.5 — native icon correction

Fix the extra white rounded frame around the macOS app icon. Native icon exports
now use a fully opaque, full-bleed teal background. macOS supplies the final
rounded mask. The existing rounded sidebar and Codex artwork is unchanged.

The macOS icon renderer reproduced the reported defect with the old ICNS and
confirmed a single teal tile with the corrected ICNS. The new master is RGB
with no alpha channel. Before/after renders are in
`outputs/icon-fix-verification-2026-09-25/`.

This build retains the previous UI and AI-title improvements and the existing
`app.orion.knowledge` vault location. Application behavior is unchanged; the
previous 1,013 renderer, 80 native, and 45 MCP test results still cover that code.
