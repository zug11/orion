# Orion 0.4.2

## What's new

- Play notes aloud with System, OpenAI, or ElevenLabs narration.
- Save ElevenLabs voice IDs with friendly names in **Settings → Voice**. Select,
  add, rename, and remove voices without adding controls to the note surface.
- Existing voice IDs are preserved as **Saved voice** when upgrading. Removing
  the selected saved voice returns narration to Orion's default voice; it does
  not delete a voice from your ElevenLabs account.
- Generate notes, podcast scripts, and illustrated slide decks from the
  active Space, with slide presentation and narration controls.
- Collapse the sidebar when you want more room to read.

Voice names and IDs are local settings shared across Spaces. Desktop API keys
remain in macOS Keychain, separately from the vault.

- **SHA256SUMS.txt** — checksums for all three downloads.

The installer is Developer-ID-signed, but **not notarized by Apple**. The build
environment did not have a notarization profile configured. macOS Gatekeeper
may therefore require approval before opening it.

## Verification and known limitations

The production renderer build, saved-voice tests, browser checks at normal and
minimum desktop sizes, and 80 native/MCP unit tests passed. The full renderer
suite has one existing failure in the presentation-wave repair scheduling test;
680 tests passed. This scheduling behavior was not changed for the saved-voice
update. Live ElevenLabs synthesis was not re-tested during this update.

The release workflow verifies the final disk image, copies Orion.app out of it,
validates nested signatures and source/renderer fingerprints, and runs the
bundled helper and Claude/Codex connector checks against that copied app.

## Dependency audit

The release audit reports two existing high-severity dependency advisories:

- PDF.js 6.1.200 is in the affected range for a scripting-related vulnerability;
  Mozilla lists 6.2.108 as patched. Orion's inspected import path extracts text
  without the PDF viewer, and the desktop app has a restrictive script CSP.
  These are relevant mitigations, not an upstream patch. See the
  [Mozilla advisory](https://github.com/mozilla/pdf.js/security/advisories/GHSA-hq66-cqwq-w95j).
- Nano ID 3.3.16 occurs under Vite/PostCSS in the build dependencies. Orion's
  direct runtime dependency is 5.1.16. The advisory concerns zero-sized custom
  generators. Dependency versions were not changed during packaging. See the
  [Nano ID advisory](https://github.com/advisories/GHSA-2v37-7h3g-55p8).
