# Orion 0.5.0

11 October 2026 · Apple Silicon · macOS 13.3 or later

Orion 0.5.0 brings AI actions into the writing surface and adds a Space voice
conversation with independent research workers. This release includes the
changes from the local 0.4.8 builds and the subsequent editor, voice and
connector integration work.

Both editions have the same application features, Claude connector and Codex

other. Writing, local imports, OCR, transcription, links, search, tasks, Spaces
and export remain useful without an AI key. Online AI and voice use configured
provider credentials and incur API usage.

## Changes

- **AI actions where you write.** Highlight text for Rewrite, Generate image
  and Link. `/write` opens an anchored writing composer. Availability follows
  the credentials required by each action; there is no toolbar AI toggle or
  persistent Continue button. Proposed text appears in the note with
  Accept/Discard and one-step Undo.
- **Links from the selection.** Search the current Space or paste a web address
  in the same destination field. Link works without an AI key and preserves
  the selected wording and formatting.
- **Chat beside the document.** The glass Chat panel supports research,
  explicitly requested note creation and reviewed edits in the attached note.
  Suggestions use actual Space context. Ordinary Chat and voice share the
  research and note-reading path.
- **Voice with independent workers.** A central voice orb and orbiting workers
  show conversation and background work together. Calls stay with the current
  Space and window through note navigation. Mute stops microphone input while
  playback and admitted work can continue. Named work orders support individual
  steering, cancellation, incremental findings and completion. Completed workers
  can open their own conversation. Reserved orbs remain visible while their
  assignments are being clarified; additional work queues behind bounded
  execution concurrency.
- **Selection as voice context.** A highlighted passage becomes priority
  reference material without starting speech or an edit. Each admitted request
  retains its captured passage through later selection and navigation changes.
  Explicit edits still use the normal review and acceptance flow.
- **Long-note research and continuity.** Workers read exact passages and track
  whole-document coverage, including an 18,000-word regression case. Voice
  receives bounded updates instead of repeatedly resending note bodies and
  complete work lists. Context usage, delivery timing, reconnect continuity and
  worker checkpoints have dedicated handling and regression coverage.
- **Current work stays current.** Chat, voice and ordinary connector reads hide
  completed tasks and their cached derivatives while preserving stored text.
  Deliberate history lookup remains available.
- **55 connector tools.** Claude and Codex integrations include version-guarded
  portable editor operations, active-editor context, existing voice work orders,
  in-note edit review, and captured-selection Write, Rewrite and image actions.
  Generation requires the current permissions and exact editor capture. The
  connector cannot accept its own proposed edits; the editor owns acceptance,
  saving and Undo.
- **Writing and document fidelity.** Toolbar timers and Flow sessions stay in
  the editor. Ruler and toolbar layout, sustained background animation, formatted
  empty paragraphs, code, tables and source-citation import/export have received
  fixes and regression coverage.

## Validation

The preceding integration pass completed 2,639 renderer tests (one skipped),
200 native tests (one ignored), and 109 MCP tests. Normal and narrow browser
fixtures covered selected-editor actions, review, image insertion and protected
selections; native interop exercised authorization, acceptance and exact saved
receipts. The release build repeats renderer, connector and packaged-artifact
checks. Final signing, notarization and checksum evidence is recorded alongside
this release after packaging.

**Live voice acceptance remains open.** Automated and controlled integration
checks do not establish the audible experience. A real provider/microphone
session still needs to demonstrate continued conversation while three workers
research, targeted clarification and cancellation, long-note grounding, orb
timing and spoken save confirmation. These voice features should be treated as
an evolving preview within the release.
