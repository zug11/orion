# Orion 0.5.3 — image quality and voice work summary

11 November 2026. Apple Silicon, Medium transcription edition.

Image generation now uses GPT Image 2.6 Sunburst by default and 2.6 Flare for
the explicit Fast choice. Both request maximum image quality, high complexity,
and lossless PNG output at 1536 × 1024. Desktop and browser paths agree. The
12-MiB attachment limit, signature validation, cancellation, review and acceptance
boundaries remain in place; existing JPEG proposals still validate. This also
updates slide illustrations that use the shared image rendering command.

Retained voice workers, errors and clarification keep ownership of the floating
dock after audio ends. Chat no longer renders its separate circle or native
circle glass underneath those controls. Clearing voice work restores the ordinary
Chat launcher. Compact and full Chat continue to embed the same call owner.

The floating pill keeps its content width when the work summary opens. Embedded
controls fill the available width without a dead right margin, including narrow
windows. The worker summary is a compact divided list with clear status labels,
research/conversation/save actions, and a close control. The large orb scene stays
in Chat. Focused workers offer Return to Space conversation in the summary.
Closing the summary or pressing Escape restores focus to its pill button.

Validation: 2,964 renderer tests passed with one existing skip; 222 native tests
passed with one existing ignore; 114 connector tests passed. Production renderer
build, Rust formatting and whitespace checks passed. Real-browser checks used the
production ChatDock, SpaceVoice and orb components with isolated local transports
at 1280 × 720 and 390 × 740 in dark and light modes. They covered retained jobs
after call end, equal collapsed/expanded pill width, Chat embedding, worker
conversation return, research visibility, draft retention, keyboard focus and
clear confirmation. Browser console showed no warnings or errors.

The image model IDs and maximum-quality parameters were verified against the
[official OpenAI image guide](https://developers.openai.com/api/docs/guides/image-prompting#model-parameters).
Provider requests and PNG/legacy-JPEG acceptance were verified with automated
fixtures. A live image request was not run: the independent credential read did
not complete, and was cancelled without retrieving or printing the key.
