# Orion 0.5.3 — word count

10 November 2026. Apple Silicon, Medium transcription edition.

Reading and editing now show a small translucent word-count pill centred at the
bottom of the text column. It stays visible as a long note scrolls. Highlighting
text shows selected words out of the note total, including selections in the
authored title and subtitle. Empty heading placeholders, formatting syntax,
source markers and separate image captions/metadata do not count as words.

Counts are transient and local to the open note. Editing reuses cached counts
for immutable paragraphs and coalesces count/selection updates into an animation
frame, without updating the vault or the application-wide state. The count
clears selection state on navigation and supports Undo. Reduced-transparency
and increased-contrast preferences get an opaque surface. Contextual selection
actions leave room for the count; narration moves the count above its controls.

The previous typing-latency and multiwindow-refresh fixes remain included.

Validation: 2,962 renderer tests passed with one existing skip, 222 native tests
passed with one existing ignore, and 114 connector tests passed. The production
renderer build, both Rust formatting checks and diff whitespace checks passed.
Browser checks covered reading/editing selections, the Done transition, an empty
note, a long scrolling note, and standard/narrow windows. One count remained
present throughout final interaction checks, with no new console errors.
