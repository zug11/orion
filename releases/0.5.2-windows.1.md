The first **Orion preview for Windows 11 x64**, based on Orion 0.5.2.

Download the Windows setup EXE from **Assets** and run it. Setup installs for
the current user and can fetch Microsoft Edge WebView2 if it is missing. This
preview is unsigned, so Windows may show a SmartScreen prompt. The SHA-256 file
is included alongside the installer.

- Write and link notes, organize them into Spaces, search your atlas, and open a
  separate writing window. Your library is saved locally.
- Import documents and webpages, recognize English text in PNG/JPEG images
  and scanned PDFs, and transcribe WAV, MP3, M4A, and MP4 recordings of up to
  30 minutes with the bundled multilingual Whisper Small model. OCR and
  transcription run offline. Note dictation uses the same local model.
- Export Markdown, offline HTML, or Word. Optional AI provider keys go in
  Windows Credential Manager.

This preview uses standard Windows window controls. YouTube import, the
Claude/Codex desktop connectors, HEIC/HEIF OCR, and system voice audio export
remain Mac features. Windows on Arm is outside this release's tested scope.
