# Orion 0.4.5 — icon controls and small-Space summaries

The Icon colours card now keeps Finder status inside the padded text column,
using the same readable helper-text scale as the description. Original / Theme
uses two equal segments with no empty third slot and wraps cleanly on smaller
layouts. Other appearance selectors size their columns to their actual options.

Across this Space now includes short notes without a 24-character minimum.
The local overview and semantic index use the same eligibility rule. Blank
starter notes, archived notes, and unfinished linked articles remain excluded;
the default starter description is not treated as knowledge. Existing indexes
are checked on load so previously excluded notes can be summarized.

Both overview request paths now explicitly support a single note and allow a
single sentence when that is all the material supports. A local summary stays
visible while AI refreshes and is labelled as a local summary instead of implying
that AI is required. Provider consent, Space boundaries, bounded context, and
late-result protection remain in place. No test notes were inserted into a
user vault; the production library was untouched.
