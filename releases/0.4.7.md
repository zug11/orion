# Orion 0.4.7

Orion 0.4.7 adds focused writing windows, an inline margins ruler, persistent
writing blocks, and a quieter frosted-glass editor toolbar. It also expands Word
support, appearance options, Space search, and the local Claude/Codex integrations.

Both editions are **Developer ID signed, Apple notarized and stapled**, and pass

stops. Both include Vision OCR, yt-dlp, Deno, and the Claude/Codex integrations.

## Writing and editing

- **Consistent frosted glass.** The native editor toolbar follows the More menu's
  material treatment. Spacing separates control groups without vertical dividers.
- **Focused writing windows.** Open a note in a dedicated window with normal
  autosave, note links, export, and the shared Close/Quit save behavior.
- **Inline margins ruler.** Adjust document margins or the selected paragraphs
  directly on the writing surface. Rapid drags preserve the latest margin and
  selection when earlier editor updates return through application state.
- **Persistent writing blocks.** Create and organize portable blocks with compact
  contextual controls. Move, upper insert, and trash controls share one row above
  the block, keeping the move handle clear of table selection controls.
- **More portable output.** Export editable Word documents, import supported DOCX
  content, and download note narration.

## Appearance, search, and integrations

- Save and reuse personal colour palettes, with bounded tuning and the curated
  Home atmosphere collection, including Opal and Ripple Glass.
- Search note and source passages within the current Space, with improvements
  to passage navigation and exact-passage AI search.
- Illustration research can search relevant Space passages adaptively and retain
  completed work for an explicit retry after an interrupted stage.
- Updated Claude and Codex integrations include version-guarded portable editor
  commands, Space search, and Word export.
