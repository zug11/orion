# Orion 0.5.1

22 October 2026. Apple Silicon installers in Whisper Small and Medium editions,
containing the same application features. The packaged application source is
committed as [5942278](https://github.com/zug11/orion/commit/59422781d07c62abc7aef2028152552cdff15eff).
The release-record commit updates publication documentation only. Both DMGs and
their source fingerprints were rechecked before publication.

## Changes

- Optional Perplexity research: enter and test the key in Settings. Voice
  workers can look up outside evidence when useful; text Chat uses web research
  only while its Web pill is selected. Provider keys remain in macOS Keychain.
- Web evidence retains its links, retrieval dates and search excerpts, including
  when a response is kept as a note. Long answers stay with the worker and can
  be read in sections without repeating the external lookup. Unsupported or
  failed research is reported as a retryable failure instead of an empty result.
- Voice findings are consolidated in the background through the selected
  Intelligence model. Related interim and completed findings can form one
  concise contribution while preserving the original worker results and
  citations. Later findings remain incremental.
- Findings and background context updates wait while voice is speaking or its
  transcript remains unfinished. Completion has priority over interim chatter;
  cancellation, changed assignments and a newer user turn invalidate stale
  prepared updates. A failed synthesis retains the original evidence and
  provides Retry voice summary.
- Import batching accounts for reading-section capacity as well as text size,
  including dense Unicode material.

The existing editor, passage comments, combined Chat/voice icon, Markdown import
subtitle fix and “Everything you care about, in context.” tagline are included.

## Verification

The implementation passed 2,882 renderer tests (one existing skip), TypeScript
and Vite production builds, 221 native Rust tests (one ignored), and 114 MCP
tests before the coordinated 0.5.1 manifest update. Both Rust formatting checks
and the Git whitespace check passed. The release pipeline rebuilds the
renderer, native app and both connectors with the 0.5.1 version and verifies
the exact bundled model and copied-out installer contents.

Browser fixtures exercised six simultaneous workers, an unfinished spoken
sentence, consolidated delivery after a pause, failure/retry, keyboard access,
light/dark themes and narrow layouts without console errors. The updated
native Preview also built and launched successfully. Those checks used
simulated audio and provider responses.

Both final installers are Developer ID signed with Hardened Runtime,
Apple-notarized, stapled and Gatekeeper-accepted. Each final image was mounted
read-only and its app independently copied out after notarization. Those copies
passed deep/strict signature checks and Gatekeeper, reported version 0.5.1 and
the production `app.orion.knowledge` identity, and contained the exact expected
Whisper model. Both bundled connectors report 0.5.1. The release pipeline also
verified all 57 connector tool schemas and 23 local library tool contracts from
the copied-out installers. No installed app was replaced or launched for these
packaging checks.

## Remaining acceptance

Live microphone/provider listening acceptance remains open. GPT-Live does not
provide an explicit response-finished/audio-done event; playback quiet plus a
settled terminal sentence is a conservative delivery heuristic. The automated
checks and notarization do not establish perceived conversational timing,
synthesis quality or live Perplexity results. No production library is seeded,
reset or copied as part of packaging.
