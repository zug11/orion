# Orion 0.4.6

> Release preparation: the changes below are approved for integration. The
> Small and Medium installers are not yet published; final package verification
> will be recorded before release.

Orion 0.4.6 gives notes more of a word processor's freedom while keeping connected
writing simple. It adds precise excerpts, flexible tables and images, six heading
levels, and narration that follows the words on the page.

## Writing and layout

- **A compact slash menu.** Type `/` in a paragraph to insert headings, tasks,
  lists, dividers, images, code, note links, excerpts or tables. Search commands
  or choose with the keyboard. The menu stays below the caret, and surrounding
  prose stays intact.
- **Exact linked excerpts.** Search titles and text across the current Space,
  open a full note, and select the sentence or passage you need. Separate
  selections can join with an ellipsis. A small source link returns to the
  original passage. Backspace removes an excerpt in one undoable edit.
- **Tables that are easier to shape.** Choose dimensions with a Word-style
  hover grid. Once inserted, Pages-style row and column rails provide selection,
  sizing and count controls. Change headers and banding, resize columns, or use
  `/delete` for a row, column or table. Removing populated rows or columns
  requires confirmation.
- **Images move freely.** Drag an image at its displayed size while the text
  wraps around it live. Captions move with it. Resize from the corners, choose
  Wrap text, Above & below or In line, and adjust text spacing. A completed move
  is one Undo step; Escape restores the original layout.
- **A contextual toolbar.** Selecting an image or table shows its relevant
  tools. Returning to prose restores writing controls. Less-used actions move
  into More as the window narrows, without a scrolling toolbar.
- **Heading 1–6.** Choose all six levels from the toolbar or slash menu. The
  reading outline and web export support them too.

## Listen and follow along

Written-note Play can dim upcoming text and highlight the current word. Click a
word to jump there, use the keyboard-accessible playback slider, or pause and
resume from the same place. Turn off **Follow text** to keep the ordinary reading
appearance. Editing or leaving the note clears its playback state.

System voices use available word-boundary events. ElevenLabs provides timing
with its audio; OpenAI audio is aligned locally using bundled Whisper, with no
extra paid transcription call. Alignment adds preparation time and may be
approximate. **Passage timing** identifies playback without reliable word timing.
Cloud passages are prepared as needed and reused when seeking.

## Clearer everyday controls

- Rename a Space directly from its switcher. Its notes, links and identity stay
  intact.
- Import knowledge uses larger supporting text, fields, source names and
  actions, including the paste and review panels.
- A clearer standalone sparkle icon makes the editor's **AI tools** easier to
  find. Its accessible name and tooltip cover writing and image generation.
  Opening the tools never starts generation; existing API-key requirements and
  preview-before-accepting behavior remain.

## Better context for images and summaries

- Selected-passage illustrations use `gpt-image-2.5-sunburst`. Your selected
  Intelligence model first reads relevant notes and original sources from the
  current Space, then prepares a visual brief. It uses the current editor text
  and respects the existing-note context setting.
- **Across this Space** uses current note content more reliably in small Spaces
  and invalidates obsolete summary caches that could keep showing a generic
  introduction. The underlying notes are preserved.
- Hidden image, table and excerpt layout metadata stays out of reading text,
  search snippets and import previews.

## Editions and existing libraries

- **Orion-0.4.6-Apple-Silicon.dmg:** Whisper Small edition.
- **Orion-0.4.6.m-Apple-Silicon.dmg:** Whisper Medium edition.

Both editions contain the same Orion features and use the existing Orion
library. Installing one replaces the other. Notes remain portable Markdown;
this update does not create a separate block database or copy the developer
preview library. Apple Silicon and macOS 13.3 or later are required.

Excerpts preserve editable quotations rather than synchronizing later source
edits. Image wrapping uses the roomier side of the image; simultaneous wrapping
on both sides is not supported. Other Markdown editors may preserve the content
without reproducing Orion's layout.
