# Orion 0.5.0 release verification

11 October 2026. Both Apple Silicon editions completed the canonical release
pipeline and independent verification of the final, stapled installer.

## Source and build

Application source: [`eaa7209`](https://github.com/zug11/orion/commit/eaa7209569bed5ef77b0398e7511287a4eb3024d).
The later release-record commit changes release documentation only.

Packaging used a clean source copy outside the development checkout, including
the real model and helper files. All 749 checked input files matched the committed
source. Retained iCloud conflict copies, unrelated local website work and temporary
build directories were excluded. The package script independently stamped and
verified the source and renderer fingerprints for each edition.

Both builds used `script/package_release.sh`, Developer ID signing with hardened
runtime, APFS drag-install images and the existing Apple notarization profile.
Each edition includes its exact expected Whisper model, version 0.5.0 of the
Claude connector and Codex plugin, and the production `app.orion.knowledge`
identity. These are release installers, separate from the local Orion Preview.

editor-action integration pass. Release preparation changed versions, documentation,
generated helpers/connectors and a CSS trailing newline; it did not change that
application logic. The canonical release builds repeated native compilation and
packaged connector tests. Final installers were mounted read-only and copied out
for independent checks after notarization; no app installation or launch was used.

## Remaining acceptance

Live microphone/provider and installed-client interaction checks remain separate.
The user's three-worker voice scenario still needs audible validation, including
continued conversation, clarification, targeted cancellation, long-note grounding,
orb timing and save confirmation. Fixture, build and signing success do not claim
that the user has tried or heard that experience. Existing app sessions and the
user's vault were not reset or seeded for release verification.
