# Orion 0.5.0 release verification

12 October 2026 rebuild. Both Apple Silicon editions completed the canonical
release pipeline, independent verification of the final stapled installer, and
native checks after launch and icon-setting changes.

## Source and build

Application source: [22a6c6e](https://github.com/zug11/orion/commit/22a6c6e466a0aea5f842e4117394d92a9548a18a).
The later release-record commit changes release documentation only. The existing
v0.5.0 tag retains the original release history; these rebuilt assets use the
exact application commit linked above.

Packaging used a clean git archive of that commit outside the development
checkout. All four bundled LFS objects (Small and Medium models, Deno and yt-dlp)
were verified against their committed object hashes and sizes. Untracked work,
retained iCloud conflict copies and temporary development files were excluded.
Only dependency and Cargo caches were shared. The canonical package script
stamped and verified the source and renderer fingerprints for each edition.

Both builds used script/package_release.sh, Developer ID signing with hardened
runtime, APFS drag-install images and the existing Apple notarization profile.
Each edition includes its exact expected Whisper model, version 0.5.0 of the
Claude connector and Codex plugin, and the production app.orion.knowledge
identity. These are release installers, separate from the local Orion Preview.

## Signing fix

The adaptive icon now changes only the in-memory application/Dock icon. It no
longer writes a Finder custom icon or its metadata into the signed application
bundle. Finder retains the packaged icon; the in-app O and running Dock icon
retain theme colours. Settings no longer ask for a writable app location.

The corrected native Preview first passed strict signature checks before and
after launch and Theme/Original changes. Then the exact app copied out of each
final notarized DMG was launched and checked with Theme enabled, Original
selected, and Theme restored. Deep/strict signatures remained valid; Gatekeeper
accepted both copies after launch. Neither acquired FinderInfo or ResourceFork
metadata. macOS may add its permitted com.apple.macl attribute; verification
does not remove it or weaken signature checks.

## Remaining acceptance

Live microphone/provider acceptance remains open. The local coordination and
installer checks do not establish audible conversation quality. Real sessions
still need to confirm neutral startup, unfinished thoughts, useful immediate
answers, several simultaneous workers, long-note grounding, source conflicts,
orb handoffs and spoken edits/saves. Voice remains an evolving preview within
this release.
