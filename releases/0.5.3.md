# Orion 0.5.3 — optional document headings

3 November 2026. Apple Silicon, Medium transcription edition.

This local release lets you start writing before you know the note's title.

- New notes start with empty title and subtitle values, without saved starter copy.
- The first two editable lines sit below the formatting toolbar. Only the
  focused empty line displays its faint Title or Subtitle hint.
- At the beginning of the body, Backspace removes the empty subtitle row,
  then the empty title row, bringing the body directly below the toolbar.
- The note remembers removed rows when reopened. Enter at the body start
  restores the title; Enter in that line restores the subtitle.
- Existing heading text stays visible and editable. Ordinary body Enter,
  Undo, structured content, input composition and body offsets stay intact.
- Optional per-note layout metadata is validated; older notes keep both rows.
- The recent native writing responsiveness and Space-summary maintenance
  changes are included in this build.

Application, Tauri, MCP, Claude connector and Codex plugin versions are 0.5.3.
The installer label is `0.5.3.m`.
