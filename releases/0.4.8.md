# Orion 0.4.8

9 October 2026 · Apple Silicon · Signed and notarized local rebuild

Orion 0.4.8 brings AI writing and links to the text selection, adds contextual
Chat suggestions, and improves continuous voice conversation with independent
research work orders.

## Editions

Both editions contain the same application features and bundled Claude connector
and Codex plugin. Their local transcription models differ:

| Edition | Release label | Installer |
| --- | --- | --- |
| Whisper Small | `0.4.8` | [Orion-0.4.8-Apple-Silicon.dmg](../outputs/Orion-0.4.8-Apple-Silicon.dmg) · 535,952,429 bytes |
| Whisper Medium | `0.4.8.m` | [Orion-0.4.8.m-Apple-Silicon.dmg](../outputs/Orion-0.4.8.m-Apple-Silicon.dmg) · 1,503,685,407 bytes |

The editions share Orion's application identity; installing one replaces the
other. Writing, local import, OCR, bundled transcription, links, search, tasks,
Spaces and export remain useful without an AI key. Online AI and voice features
use configured provider credentials and incur API usage.

## What's changed

- **AI actions where you write.** The toolbar AI toggle and persistent Continue
  button are removed. `/write` and **More → Write with AI** open an anchored
  composer with Sentence, Paragraph or Section and optional instructions.
  Highlighting text exposes Rewrite, Generate image and Link. Availability
  follows the credentials needed by each action; selecting text or opening a
  composer does not itself call a provider. Writing retains preview,
  Accept/Discard and one-step Undo.
- **One link destination field.** Search notes in the current Space or paste a
  web address while preserving selected wording and formatting. Linked-article
  creation remains available. Link works without a key. Explicit Open and
  Cmd/Ctrl-click open web links in the browser. Live Write and Link inputs use
  frosted HTML surfaces; the toolbar and More menu retain native Apple Liquid
  Glass.
- **Chat grounded in the Space.** Suggested prompts are generated from actual
  note passages and the attached note, refresh with context, and can be refreshed
  explicitly. Unchanged context reuses the current suggestions; unavailable
  suggestions do not fall back to stock prompts. Chat can research notes and
  sources, create notes when explicitly requested, and propose edits in the
  actual note for review and acceptance.
- **Continuous voice with identifiable work orders.** The empty composer's
  voice button becomes Stop during a call. Independent research continues while
  the conversation proceeds, with named cancellation, targeted corrections,
  citations and compact progress/results. Buffered turns retain spoken order;
  a cancelled request cannot be revived by its delayed delegation. Manual
  reconnect restores assignments and confirmed saves without rerunning them.
- **Successive spoken assignments.** Explicit work requests can start from
  their exact transcript without waiting for a separate delegation event or an
  additional intent call. Silence-delimited turns remain independent, including
  batched transcripts. A late duplicate delegation cannot restart an unchanged
  job. Targeted corrections, cancellation and save authority remain guarded.
- **Whole-note reading in Chat and voice.** Research can read a long note or
  source in exact passages and track beginning-to-end coverage. An 18,000-word
  regression note fits in one batch while another independent request completes.
  Per-document and total-workspace limits remain bounded; oversized or evicted
  evidence is explicitly partial. Detailed passages stay with the research
  worker, while voice context and final saved citations remain compact.
- **Quieter voice context and better result timing.** Navigation updates the
  selected-note context; ordinary typing does not repeatedly send note text.
  Work orders send changed fields, and actual provider context usage reduces
  optional updates and triggers a bounded continuity checkpoint. Transcript
  activity guides result delivery, with a bounded local wait despite background
  noise. Corrections affecting a finding resolve before its old result is
  offered. Saves are confirmed only after persistence, with duplicate-save
  protection across corrections and reconnects.
- **Current work for agents.** Chat, voice and MCP reads hide completed to-dos
  and cached derivatives by default while preserving the stored text. Scoped
  history reads remain available. Exact edits retain original versions and
  offsets, and all content access stays within the selected Space.
- **Editor reliability.** Table selections retain their true selection when
  linking. Formatted empty paragraphs no longer turn their internal blank-space
  marker into escaped literal text after saving and reopening.

## Verification and release status

Source and local-preview verification completed before packaging:

- 178 renderer suites / 1,976 tests passed; TypeScript and the production
  renderer build passed.
- Native Rust: 128 passed, one intentionally ignored. MCP Rust: 57 passed.
  Formatting checks passed.
- Normal and narrow browser fixtures covered editor actions and voice
  orchestration with controlled responses. The rebuilt native Preview passed
  bundled connector/plugin checks, source comparison, deep/strict signature
  verification and launch. The current Preview could not be visually inspected
  because the Mac was locked.

**Both final DMGs passed artifact acceptance.** Each installer is Developer ID
signed, accepted by Apple, stapled and accepted by Gatekeeper. An independent
check mounted each delivered DMG read-only, copied out its app and verified the
production identity, version 0.4.8, hardened runtime, microphone entitlement,
deep/strict signatures, app Gatekeeper, exact Whisper model, both bundled
connector versions and source/renderer fingerprints. The canonical packaging
checks also ran the helper commands and connector/plugin harnesses from the
copied-out installers. All 626 compared build-source and configuration files
matched the workspace.

See the [SHA-256 checksums](0.4.8-sha256.txt),
[Apple acceptance records](0.4.8-notarization.json), and
[artifact verification report](../outputs/release-0.4.8-work-orders/verification.md).
No GitHub release or asset publication has been performed for 0.4.8.

**Live voice acceptance remains open.** A real microphone/provider session must
still demonstrate three successive spoken assignments, including the user’s
18,000-word note, beginning/middle/end grounding, continued conversation, targeted
cancel/correction, reconnect, a single persisted save and its audible
confirmation. A successful transport send or acknowledgement does not establish
that speech was heard. The local delivery wait bound does not force provider
playback or bypass a pending correction to the same finding. Actual native
default-browser opening also remains outside the recorded editor smoke test.
