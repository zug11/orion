# Orion 0.6.0

Orion 0.6.0 brings the latest Preview improvements into the public Mac release and adds updates from inside Orion.

### Updates without another DMG

Install 0.6.0 once using the DMG. From then on, Orion checks GitHub Releases for newer versions and shows a small update button when one is available. Download when you choose, then select **Restart and update**. Orion saves every open window before installing. Settings also includes **Check for updates**.

Updates are signed with Orion's dedicated update key. The native host verifies the download before installation; a failed download or signature check leaves the installed app in place. The website remains the public download page.

### Dictation that keeps your meaning

Record into a note with the editor microphone. Whisper transcribes on your Mac. With a key configured for the selected AI provider, Orion can remove hesitations and accidental repetition, add punctuation and paragraph breaks, recognise lists and explicit tasks, and apply clear self-corrections before inserting the result.

Your wording, meaning, uncertainty and intentional emphasis are preserved. The complete original transcript stays attached to the note and remains recoverable through **Original dictations**. Without a configured key, dictation uses only local Whisper. Unavailable or failed AI cleanup falls back to that original transcript too.

Processing stays in the microphone button, without status bubbles over your writing. During cleanup, choose **Use original dictation** from that same button to insert the local transcript immediately.

### A quieter voice and text conversation

- Voice waits for you to speak instead of greeting you automatically.
- The text composer begins as a thin pill and grows with your prompt.
- Voice mute, send and stop controls share the composer; the extra Talk to Space pill is removed while chat is open.
- Stop uses a square icon, mute uses familiar microphone icons, and the sidebar chat mark is aligned with its neighbours.
- Keep talking while the other orbs research. Findings and citations return to the conversation without a visible worker queue.

The responsive editor, multi-window save fixes, edit-only word count, flexible headings, scroll-driven voice/chat panel, and high-quality GPT Image 2.6 generation from 0.5.3 are included.

### Download

**Apple Silicon Mac · macOS 13.3 or later · Whisper Medium.** Includes on-device transcription, the Claude connector and the Codex plugin. Writing and local knowledge tools remain useful without an API key.

Open the DMG and drag Orion to Applications, replacing the previous Orion app. Your existing library is retained. Orion Preview remains a separate application with its own library.

The `.app.tar.gz`, signature and `latest.json` assets are used by Orion's updater. For a first installation, use the DMG.
