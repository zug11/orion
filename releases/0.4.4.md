# Orion 0.4.4

## What's new

- Small multi-source imports now read independent sources concurrently and use
  up to six disjoint writers. In a fresh Space, clear non-overlapping ideas can
  skip an extra planning call; ambiguous, guided, task-bearing, or existing-note
  imports keep the full shared plan.
- Ready sources can be reviewed and imported while other files finish preparing.
  Pending inputs stay queued, and selectable PDF pages extract through a separate
  four-slot local pool.
- One fair six-call provider budget now covers imports, generation, Chat, images,
  speech, and background work. Recoverable connection failures retry within
  bounded limits, while safe checkpoints preserve completed work for Resume.
- Decks and podcasts can use authored notes even when a Space has no Sources.
  Orion selects relevant note context, builds one outline, and writes independent
  sections in parallel without a final rewrite.
- Imports preserve distinct supported ideas instead of forcing them into a
  twelve-note cap or merge ratio. The thirty-output atomic safety boundary
  remains, and recovery combines only identical title-and-thesis seeds.
- Imported notes now carry deliberate link phrases and typed `supports`,
  `qualifies`, and `conflicts` relationships with reasons in the connections
  inspector. Shared vocabulary or provenance alone never creates a connection.
- Writer validation keeps questions, hypotheses, recollections, and
  interpretations properly qualified, and repairs repeated explanatory
  paragraphs before anything is applied.

Actual duration still depends on the selected model, reasoning effort, source
material, and provider response time.

## Verification and known limitations

The production renderer build and Rust formatting checks passed, along with 773
renderer tests (81 test files passed and one skipped), 53 native tests, and 28
MCP tests.

The release workflow verifies the final disk image, copies Orion.app out of it,
validates nested signatures and source/renderer fingerprints, runs the four
bundled helper version checks, and exercises the Claude and Codex connector
contracts against that copied app.

This release does not claim a live Sol latency benchmark or an end-to-end media
import test.

## Dependency audit

The release audit reports two existing high-severity dependency advisories:

- PDF.js 6.1.200 is in the affected range for a scripting-related vulnerability;
  Mozilla lists 6.2.108 as patched. Orion's inspected import path extracts text
  without the PDF viewer, and the desktop app has a restrictive script CSP.
  These are relevant mitigations, not an upstream patch. See the
  [Mozilla advisory](https://github.com/mozilla/pdf.js/security/advisories/GHSA-hq66-cqwq-w95j).
- Nano ID 3.3.16 occurs under PostCSS in the build dependencies. Orion's direct
  runtime dependency is 5.1.16. The advisory concerns zero-sized custom
  generators. Dependency versions were not changed during packaging. See the
  [Nano ID advisory](https://github.com/advisories/GHSA-2v37-7h3g-55p8).
